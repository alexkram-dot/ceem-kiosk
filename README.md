# CEEM Kiosk

Интерактивная цифровая витрина Коллекции эубиотических и эпифитных
микроорганизмов Кубанского государственного аграрного университета.

## Запуск локально

Требуется Node.js 24 или новее. Рекомендуемая версия указана в `.nvmrc`.

```bash
npm ci
npm run dev
```

## GitHub Pages

Проект уже содержит workflow `.github/workflows/pages.yml`. После включения
GitHub Pages в режиме **GitHub Actions** каждый push в ветку `main` автоматически
собирает и публикует статическую версию сайта.

Адрес после публикации:
`https://alexkram-dot.github.io/ceem-kiosk/`

Для ручной проверки статической сборки в Linux:

```bash
npm ci
npm run build:pages
```

Готовые файлы появятся в каталоге `dist/client/`.

## Состав MVP

- 255 уникальных открытых карточек КЭЭМ с прямыми ссылками на источник;
- 30 штаммов в демонстрационной подборке;
- просмотр по применению и по систематике;
- поиск по названию и номеру реестра;
- 13 подготовленных визуализаций и единая заглушка для остальных карточек;
- двуязычный интерфейс RU/EN;
- адаптация под сенсорный терминал и автоматический возврат на заставку.

## Обновление каталога

Данные открытых карточек хранятся в `app/catalog.generated.json`. Для повторного
получения актуальной публичной выборки используется:

```bash
node scripts/scrape-catalog.mjs
```

После обновления каталога выполните `npm test` и проверьте изменения перед публикацией.
